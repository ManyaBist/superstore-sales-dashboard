# Superstore Sales Dashboard | 2014–2017

An interactive Excel dashboard analyzing 9,994 sales transactions 
from a US retail superstore across 4 years (2014–2017).

## Dashboard Overview
Built using Microsoft Excel with Pivot Tables and Pivot Charts.

## Key Insights
- Technology is the top revenue category at $836K
- West region leads all regions with $725K in sales
- Consumer segment is the most profitable at $134K profit
- Revenue shows consistent growth from 2014 to 2017

## Charts Included
- Sales by Category
- Sales by Region
- Profit by Customer Segment
- Monthly Sales Trend (2014–2017)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts

## Dataset
Sample Superstore dataset from Kaggle (9,994 rows)
